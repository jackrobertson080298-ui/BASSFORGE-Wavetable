# BASSFORGE 2.2 – Interactive Oscillator Surfaces

- Three mouse-interactive oscillator panes with APVTS host automation gestures.
- OSC A: horizontal drag adjusts FM; Alt+drag adjusts phase warp.
- OSC B: vertical drag adjusts level; Alt+horizontal drag adjusts tuning.
- Harmonic pane: draw individual amplitudes for partials 1–8.
- Previous/next preset buttons navigate the populated dropdown.
- Oscillator surfaces reflect current harmonic parameters on the editor timer.

## Important limitations
This is a source-level feature update, not a verified binary. It has not been compiled or tested inside FL Studio in this environment. This does not implement Serum-style arbitrary wavetable drawing or drag-and-drop modulation. The current harmonic editor changes additive partial amplitudes, not arbitrary waveform points.
