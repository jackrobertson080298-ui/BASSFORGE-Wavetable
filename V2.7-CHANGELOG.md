# BASSFORGE v2.7 — Init preset

- New plugin instances start on **Init**, not Reactor.
- Init is selectable from the main preset dropdown and reachable with previous/next navigation.
- Init resets all registered parameters to their defaults, then applies a clean sine-based, sustained starting patch with effects bypassed and other oscillator layers disabled.
- Init remains in the program list, so hosts can recall it and the selected name is stored with project state.
- Existing 30 factory patches retain their original indices.

## Verification
Source checks and ZIP validation only. Windows/JUCE compilation and FL Studio playback are not verified.
