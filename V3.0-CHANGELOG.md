# BASSFORGE 3.0 — Wavetable Engine Foundation

- Added precomputed 2048-point band-limited waveform tables with 11 octave mip levels.
- Four morphable frames: sine, saw, square, triangle.
- Interpolates between adjacent samples, wavetable frames, and adjacent mip levels.
- Independent wavetable position and mix for OSC A and OSC B.
- New APVTS IDs: wtmix, wtposition, wt2mix, wt2position.
- Default wavetable mix is zero, retaining existing preset sound unless enabled.
- No heap allocation inside wavetable sample() or processBlock().
- Shared wavetable data is created once per processor instance.
- No custom wavetable drawing/import, modulation-matrix routing, or stereo unison yet.
- Not compiled or audio-tested in FL Studio. Verify CPU, spectrum, and note-on behaviour before release.
