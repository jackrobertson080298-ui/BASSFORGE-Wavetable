# BASSFORGE 3.2 — Wavetable aliasing repair

- Custom WAV and drawn waveforms now build 11 band-limited mip levels with a 2048-point FFT on the UI/state-loading thread.
- Removes DC from custom waveforms before playback.
- Frequency-dependent octave mip selection, crossfaded between adjacent mip levels.
- Fixed zero-harmonic upper levels in built-in wavetable generation.
- No new parameter IDs; prior project state remains structurally compatible.
- Legacy oscillator/FM/unison implementation otherwise unchanged.

Limitations: Shared-pointer publication still has possible reference-count/reclamation activity on the audio thread; this needs a production-safe deferred reclamation design. Full per-unison FM, higher-order oversampled FM, and CPU/host validation remain incomplete.
