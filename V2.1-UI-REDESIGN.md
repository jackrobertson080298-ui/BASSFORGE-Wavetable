# BASSFORGE 2.1 — Rack Interface Redesign

Visual reference: user-provided dark, compact Serum-style synth screenshot. This is an original interface design, not a reproduction of the referenced plugin.

## Changes
- New charcoal/teal visual language, compact header, navigation rail, three oscillator waveform preview cards, lower control deck and MIDI keyboard.
- OSC page opens by default.
- Oscillator previews read current FM, ratio, warp, secondary oscillator waveform/level and all eight additive partial parameters. These previews are **parameter-derived** and not real-time output oscilloscopes.
- Existing parameter attachments, legacy synthesis engine, preset browser, FX and LFO pages are preserved.
- Updated version to 2.1.0.

## Known limitations
- This is a UI redesign of the existing BASSFORGE 2.0 code, not a complete Serum/Vital-equivalent synth.
- Waveform displays are non-interactive; actual oscillator editing uses the controls in the OSC page.
- No arbitrary wavetable import/drawing or modulation matrix.
- No successful JUCE compilation or FL Studio runtime test performed in this environment.
- Bank restoration remains dependent on the external ZIP path.
