# BASSFORGE 2.8 — DSP quality pass

Changes to the Dual Layer Engine:
- Triangle oscillators use Nyquist-capped odd harmonic synthesis, avoiding the naive asin(sin) triangle's high-frequency aliasing.
- Character distortion now includes oscillator-mix gain compensation and a gentler gain law.
- The existing TONE control now drives a cascaded two-stage character low-pass filter (700–14200 Hz), leaving the clean BODY layer independent.
- Transient enhancement is reduced to avoid exaggerated clicks.

Legacy engine is unchanged. No new preset parameter IDs are introduced, so old presets remain structurally compatible.

IMPORTANT: This is a source-level DSP revision. It has not been compiled against JUCE, auditioned in FL Studio, or verified for sound quality. Use a fresh plugin build and compare at matched loudness.
