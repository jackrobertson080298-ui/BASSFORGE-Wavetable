# BASSFORGE 2.3 — Polyphony and Envelope Development Build

- Added poly/mono/legato mode and selectable 2/4/6/8/12-voice cap.
- Reworked voice allocation to steal the quietest or releasing voice instead of always voice zero.
- Added independent amplitude ADSR (attack, decay, sustain, release) to both legacy and dual-layer paths.
- Added interactive, automatable ADSR controls and voicing selectors to ENGINE page.
- Retained v2.2 oscillator interaction, bank browser and original visual theme.
- Defaults aim to preserve older patches but envelope behaviour can differ from previous versions.

## Known limitations
- Legato is last-note priority, without held-key stack or portamento.
- No arpeggiator, drawable modulation curves or full modulation matrix yet.
- Build not verified against JUCE on Windows; GitHub Actions is required to establish compile status.
- No DAW integration or audio-quality tests performed in this environment.
