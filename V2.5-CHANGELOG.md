# BASSFORGE 2.5 — Waveform Tools (development build)

- OSC A now offers sine, saw, metal, triangle, square and variable pulse. Existing enum indices 0–2 are unchanged for backwards compatibility.
- OSC B retains sine/triangle/saw/square, with variable pulse width when square is selected.
- OSC B hard sync resets its phase on OSC A cycle wrap.
- Three host-automatable controls added to OSC page; new parameters included in APVTS state and preset interchange.
- Preserves v2.4 LFO, bank browser, polyphony and legacy synthesis.

Limitations: triangle is not fully bandlimited, hard sync can alias, sync is binary thresholded, not all oscillator features are available in legacy engine. No verified JUCE build or FL Studio test.
