# BASSFORGE v1.1 — Stability and oscillator controls

- Bank ZIP is indexed into an in-memory dropdown; selecting an entry loads it.
- Current patch name is visible and persisted with FL Studio project state.
- Invalid ZIP entries are skipped; all entries are validated before entering the browser.
- Factory presets remain selectable.
- OSC tab adds oscillator FM ratio, phase warp, saw/metal blend and waveform selection for the v1.0 dual-layer engine.
- Existing visual design retained.

## Known limitations

- Bank contents are retained only for the current plugin/editor session; project state retains the loaded patch parameters and name, not the whole bank ZIP. Reimport the bank to browse it again.
- This is not feature-equivalent to Serum or Vital.
- Not compiled or auditioned on Windows yet. Build with GitHub Actions, and test loading ZIPs and reopening FL Studio projects.
