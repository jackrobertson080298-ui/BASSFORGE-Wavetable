# BASSFORGE 2.4 — Drawable LFO Studio (development build)

- Three editable 16-point custom LFO curves. Select CUSTOM in the existing LFO shape dropdown to hear the drawn curve.
- Every point is an APVTS parameter, saved in DAW state and `.bfpreset` files, and automatable.
- Interpolated curves wrap seamlessly at the end of the LFO cycle.
- Existing rate, retrigger/free-run/one-shot, depth, keytrack and destination routing retained.
- No heap allocation inside the audio callback for curve lookup.
- Existing v2.3 voice engine, presets, FX, OSC editing and visual theme retained.

## Known limitations
- LFO destinations remain one-per-LFO; no drag-and-drop matrix yet.
- Curve editor is 16-point step-grid editing, not Bezier handles.
- No successful JUCE compilation or FL Studio validation performed in this environment.
