# BASSFORGE 3.1 — Advanced engine integration (experimental)

Implemented in source:
- Single-cycle custom wavetable editor on new WAVETABLE page; WAV import resamples up to 262144 input samples into one 2048-sample cycle.
- Custom wave mix and project/preset state serialization.
- 1–8 voice stereo unison with detune and constant-power panning. Note: unison voices currently use the shared built-in wavetable, not the complete FM/character oscillator.
- 8-slot bipolar modulation matrix: LFO 1–3, velocity, keytrack -> FM, cutoff, drive, rasp, WT A/B, pitch, filter resonance.
- 3-mode topology-preserving state-variable filter (LP/HP/BP), resonance and wet mix.
- Optional frequency-dependent phase-modulation index reduction, a basic alias guard. NOT full anti-aliased FM.
- Default new controls are neutral for backward compatibility.
- Existing rack UI preserved; new WAVETABLE tab exposes new controls.

Known limitations:
- Imported arbitrary WAV content is treated as one cycle, not automatically segmented into a multi-frame wavetable.
- Custom waveform playback is not mipmapped or band-limited. It may alias on high notes.
- Unison and FM paths are not yet fully integrated; stereo unison uses the built-in wavetable rather than the full character signal.
- No 2-filter routing matrix, granular/spectral engine, sample synthesis, spectral resynthesis, drag/drop modulation, or custom multi-frame editor.
- Wavetable sharing uses immutable shared pointers, but reference-count changes can occur on the audio thread; a production build should use a deferred-reclamation strategy.
- No Windows/JUCE compile or FL Studio playback test has been performed.

Do not release this as a production synth before compilation, host validation, spectral tests and CPU profiling.
