# BASSFORGE v1.0 – Dual Layer Engine (experimental)

## What changed
- Existing SYNTH / FX / LFO layout retained, with matching ENGINE page.
- Opt-in `engine10` processing. Existing factory patches and saved projects retain legacy DSP until enabled.
- BODY: mono sine fundamental, body low-pass, dedicated transient envelope.
- CHARACTER: FM / warped sine / PolyBLEP saw blend, character-only saturation, separate high-pass crossover.
- Character generated at 2x internal sample rate and downsampled with fixed 9-tap FIR. This is a basic anti-alias measure, not equivalent to full professional oversampling or fully alias-free FM.
- 5 new automatable parameters, saved in plugin state and `.bfpreset` files.
- Fixed-size voice storage; no per-note heap allocation. Delay/reverb/chorus buffers still allocate once in `prepareToPlay`.

## Caveats
- Not yet compiled on Windows or audio-auditioned. Run GitHub Actions and verify in FL Studio.
- Some previous factory presets may change if you enable ENGINE; the default is OFF for compatibility.
- 2x processing costs more CPU. Not a full Serum 2 feature replacement.
- Voice stealing, stereo width and pitch tracking warrant further testing.

## First test
Enable ENGINE, set BODY 0.75, CHARACTER 0.55, CROSSOVER 0.40, HARMONICS 0.55, TRANSIENT 0.65. Disable FX and compare F1, F2, F3 at conservative output.
