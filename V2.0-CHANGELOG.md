# BASSFORGE 2.0 — Oscillator Lab (development build)

- Two independently controlled character oscillators: primary FM/warp and second sine/triangle/PolyBLEP saw/square, with tune and level.
- Editable eight-partial additive oscillator with per-partial level and anti-alias Nyquist culling. Enable with EDITED WAVE MIX on OSC tab and DUAL LAYER ENGINE on ENGINE tab.
- Parameters fully automated and included in preset exports and plugin state.
- Bank ZIP path retained in project state; editor attempts to restore the bank and active preset selection. Bank file must remain in same location.
- Existing 30 factory presets and original legacy engine remain.

## Important limitations

This is a significant prototype, **not feature parity with Serum or Vital**. No arbitrary wavetable drawing/import, no drag-drop modulation matrix, no full standalone persistent preset database, and no DAW audio QA. The JUCE Windows build and FL Studio integration have not been executed here.

The new additive oscillator is computed in the oversampled synthesis loop (no waveform buffers allocated per voice); CPU cost is higher when enabled. Test high polyphony.
