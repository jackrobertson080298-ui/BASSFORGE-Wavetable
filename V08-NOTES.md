# BASSFORGE v0.8 Key Tracking

Adds per-LFO KEY TRACK slider on the existing LFO page. -1 = slower on higher notes; 0 = tempo-only; +1 = twice as fast per octave higher, relative to C4/MIDI 60. Rate is clamped to 1/16x–16x of the selected base rate. Existing presets default to zero tracking. Note-tracked free-running mode uses note-dependent phase speed; it is not transport-phase locked across pitches.

For clean punch: use moderate FM/rasp, controlled distortion, and keep sub centered. Existing sound engine otherwise unchanged.

Not compiled or auditioned on Windows.
